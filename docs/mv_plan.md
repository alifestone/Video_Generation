## 故事

**一句話**：一股 **靜默** 正把世界的顏色、聲音與動態抹成灰色定格；CSFCCA 喚醒 AI 救援程式 **LUNA**，她和 **ECHO** 必須在倒數歸零前，從 **訊號塔** 把整座 **城市** 重新「播」回來。

**主題**：創作讓世界重新動起來；**靜默** 不會徹底消失，所以創作必須一直繼續。　**基調**：冷酷未來感，帶懸疑，最後解決。　**結局**：勝利，但留下伏筆（**靜默** 沒有完全消失）。

### 靜默（`@silence`，state，待確認）

吞沒世界的現象。被吞沒的區域顏色、聲音、動態全部停止，變成灰階的定格畫面。沒有形體或核心。

| 項目 | 內容 |
| --- | --- |
| 顏色 | 飽和度降到 0（純灰階），亮度不變 |
| 動態 | 區域內的一切停在半空：雨滴、水花、煙、旗子、行人都靜止 |
| 邊界 | 被吞沒與未被吞沒的區域之間，是一條約 1 m 寬的漸層帶；顏色在帶內由飽和逐漸變灰；帶內有細小、靜止的灰色顆粒 |
| 湧升 | Prechorus 結尾起出現：一道由下往上湧向 **LUNA** 的邊界帶（約 1 m 厚、帶內是細小的灰色顆粒），在已經灰色的街景前看得出是一層往上移動的顆粒霧；它和 **衰弱褪色** 會在 bar 21 於她身上會合，把她完全定住 |
| 擴散 | 邊界向外推進，平常約每秒 30 m（2026-10-23 使用者改，原為每秒 1 m）；Prechorus（bar 17–20）加速到約每秒 100 m，Chorus 1 起依各鏡指定（Chorus 1：**廣播衝擊波** 恢復的街區從 [25,3] 起被邊界以每秒約 15 m 從外往內吞回（約 10 秒吞完，[30,1] 消失）；**訊號塔** 塔身上的灰色從 [26,1] 離地約 5 m 起以每秒約 5 m 往上爬，bar 34 開頭約離地 95 m，比她爬得慢）；推進時沒有光、沒有聲音特效。這個速度只用來決定一鏡之內看得到多少推進，不用來推算全片的地理與時間 |

**不是**：不是黑霧、黑洞、漩渦或怪物；不是冰凍：沒有冰晶與白霜

### 觸碰恢復（`@restore_touch`，state，待確認）

**LUNA** 身體碰到的 frozen 物體短暫恢復原本的顏色與動態，之後又被 **靜默** 蓋回灰色定格。只有 **LUNA** 有這個能力（**ECHO** 與平台沒有）。Hook 是小小的預告（雨滴），Verse 她才真正發現這個能力。

| 項目 | 內容 |
| --- | --- |
| 恢復 | 被碰到的物體整個恢復（一整個水窪、一整顆氣球連繩子、一整個人），在 2 幀內恢復原色，動作從停住的地方接著進行；恢復時沒有發光、光暈或粒子特效 |
| 持續時間 | 依鏡頭指定（Hook 的雨滴約 12 幀）；duration 是恢復維持的時間，不含之後 6 幀的退回 |
| 退回 | 時間到時顏色在 6 幀內退回灰階、動作停在當下的位置 |
| 腳步區塊 | Prechorus（bar 17）起能力變強：她每一步落地（地面與車頂都算），以落腳點為中心、一定半徑內短暫恢復：圓內碰到的個別物體（**懸浮車**、雨滴、路人）整個恢復，連續的表面（路面、牆面）只恢復圓內那一塊。從落腳那一幀起算：4 幀擴成圓、維持 18 幀、6 幀退回，共 28 幀（以輸出時間計，慢動作也不拉長）。她越衰弱（**衰弱褪色**）半徑越小：bar 17–18 約 3 m、bar 19 約 2 m、bar 20 約 1 m；Chorus 1 廣播後她恢復，半徑回到約 3 m |
| 雨滴 | 恢復的雨滴是透明水珠，映出附近光源的顏色（平台白光、**ECHO** 的青色光帶），會往下落；退回灰色時停在半空。遠景裡水珠太小，後製把恢復中的水珠亮度提高到約 2 倍，讓它們看得見 |

**不是**：不是 **LUNA** 身上發出的光或衝擊波（衝擊波是 Chorus 1 的廣播）；Verse 以前，恢復範圍只有她身體直接碰到的東西；Prechorus 起只多了腳步的圓形區塊（footstep_patch），不是一圈圈往外推的衝擊波

## 詞彙

**轉場**

| 值 | 意思 |
| --- | --- |
| `cut` | 直切。在 span.from 的拍點直接換成新畫面，沒有任何效果 |
| `cut_on_action` | 直切，前一鏡結尾與這一鏡開頭是同一個動作的前後兩段 |
| `match_cut` | 直切，前一鏡結尾與這一鏡開頭有同一個形狀在畫面同一位置 |
| `flash_white` | 前一鏡最後 N 幀變成純白 #ffffff（參數 frames），新畫面從純白後的第一幀直接出現，不淡入 |
| `whiteout` | 前一鏡亮度在 in_beats 拍內逐漸升到純白，新畫面再從純白在 out_beats 拍內淡出 |
| `fade_from_black` | 從純黑 #000000 在 N 拍（或 frames 幀）內淡入成畫面 |
| `fade_to_black` | 畫面在 N 拍內淡出成純黑，下一鏡從純黑開始 |
| `dissolve` | 前後兩個畫面交疊 N 拍，前一鏡淡出的同時新畫面淡入 |

**後製效果**

| 值 | 意思 |
| --- | --- |
| `flash_frames` | 畫面整個變純白 N 幀後回到原畫面（不換鏡） |
| `glow_pulse` | 指定的發光物亮度短暫抬升再回落，畫面其他部分不變；不是全白 |
| `shake` | 整個畫面震動 N 幀，位移不超過畫面寬 1% |
| `chromatic` | RGB 色差分離 N 幀 |
| `speed_ramp` | 影片速度變化（參數 from/to 倍速） |
| `freeze` | 畫面停在某一幀不動 |

**變化量**

| 值 | 意思 |
| --- | --- |
| `small` | 首尾幀幾乎相同（只有呼吸、眨眼、輕微浮動）；只用首幀生成，不寫末幀也可以 |
| `medium` | 主體狀態或位置明顯改變，但構圖不變；必須寫 last_frame，用首尾幀生成 |
| `large` | 構圖、景別或主體大幅改變；必須寫 last_frame，考慮拆成兩鏡 |

**景別**

| 值 | 意思 |
| --- | --- |
| `ECU` | 大特寫，只拍眼睛或臉的一部分 |
| `CU` | 特寫，整張臉，下緣到下巴 |
| `MCU` | 近景，胸口以上 |
| `MS` | 中景，腰以上 |
| `MLS` | 中遠景，膝以上 |
| `FS` | 全身，頭頂到腳底都在畫面內 |
| `LS` | 遠景，人物高度不到畫面高的 1/2 |
| `ELS` | 大遠景，人物高度不到畫面高的 1/8，或畫面中沒有人物的環境全景 |
| `INSERT` | 物件或特效的特寫插入鏡，畫面中沒有角色的臉 |

**運鏡**

| 值 | 意思 |
| --- | --- |
| `static` | 鏡頭完全不動 |
| `push_in` | 鏡頭往前推近 |
| `pull_out` | 鏡頭往後拉遠 |
| `pan_left` | 鏡頭原地向畫面左轉 |
| `pan_right` | 鏡頭原地向畫面右轉 |
| `tilt_up` | 鏡頭原地往上仰 |
| `tilt_down` | 鏡頭原地往下俯 |
| `track` | 鏡頭平移跟著主體 |
| `crane_up` | 鏡頭垂直升高 |
| `crane_down` | 鏡頭垂直下降 |
| `orbit_left` | 鏡頭繞主體往畫面左繞 |
| `orbit_right` | 鏡頭繞主體往畫面右繞 |

**運鏡速度**

| 值 | 意思 |
| --- | --- |
| `slow` | 整鏡內畫面變化不超過 10%（推拉：主體大小變化 ≤10%） |
| `medium` | 整鏡內畫面變化 10–30% |

**角度**

| 值 | 意思 |
| --- | --- |
| `eye` | 平視，鏡頭與主體眼睛同高 |
